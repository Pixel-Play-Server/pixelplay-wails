PIXEL PLAY ← descargas
Linux · x86_64

Instalá el launcher
en un comando.

Copiá, pegá en la terminal y listo. El script baja el binario, lo deja en ~/.local y crea el acceso en el menú de aplicaciones.

1 · Instalación rápida

curl -fsSL https://launcher.pixelplay.gg/dl/install-linux.sh | bash

Después abrí Pixel Play desde el menú, o corré pixelplay-launcher.

2 · Dependencias (si no abre)

El launcher usa WebKitGTK. Si falla al iniciar, instalá esto según tu distro:

Ubuntu / Debian / Linux Mint / Pop!_OS

sudo apt update
sudo apt install -y curl libwebkit2gtk-4.1-0 libgtk-3-0

Si no encuentra libwebkit2gtk-4.1-0, probá libwebkit2gtk-4.0-37.

Fedora

sudo dnf install -y curl webkit2gtk4.1 gtk3

Arch / EndeavourOS / Manjaro

sudo pacman -Syu --needed curl webkit2gtk-4.1 gtk3

3 · Instalación manual (paso a paso)

  1. Crear carpeta e instalar el binario
mkdir -p ~/.local/share/pixelplay ~/.local/bin
curl -fL -o ~/.local/share/pixelplay/pixelplay-launcher \
  https://launcher.pixelplay.gg/dl/pixelplay-launcher
chmod +x ~/.local/share/pixelplay/pixelplay-launcher
ln -sfn ~/.local/share/pixelplay/pixelplay-launcher ~/.local/bin/pixelplay-launcher
  1. Abrir
pixelplay-launcher
# o:
~/.local/share/pixelplay/pixelplay-launcher

Asegurate de tener ~/.local/bin en tu PATH (en la mayoría de distros modernas ya está).

4 · Actualizar

Desde el launcher: debería ofrecer update solo (drop-in del binario).

O volvé a correr el instalador:

curl -fsSL https://launcher.pixelplay.gg/dl/install-linux.sh | bash

5 · Desinstalar

rm -f ~/.local/bin/pixelplay-launcher \
  ~/.local/share/pixelplay/pixelplay-launcher \
  ~/.local/share/applications/pixelplay-launcher.desktop \
  ~/Desktop/pixelplay-launcher.desktop
# datos del juego/launcher (opcional):
# rm -rf ~/.local/share/pixelplayclientv3
